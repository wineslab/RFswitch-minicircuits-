        Device information
        
    
          
  • Model: USB-2SP4T-852H — dual SP4T (COM A & COM B, each → ports 1–4), 50 Ω, SMA female, USB Mini-B.
    • 
          
  • Connected now: serials 12602090027 & 12602090016, firmware B8.
    • 
          
  • 852H family (datasheet): 10–8500 MHz, solid-state absorptive, daisy-chain up to 35 modules over the serial control bus.
    • 
          
  • Panel layout (bottom row of SMA): A1 A2 [COM A] A3 A4 | B1 B2 [COM B] B3 B4.
    • 
          
  • Transport: USB HID, VID 0x20CE / PID 0x0022. ASCII SCPI is written to interrupt-OUT endpoint 0x01; the reply comes back on interrupt-IN 0x81 as a 64-byte HID report (byte 0 is the report id and is dropped).
    • 
          
  • Addressing: a command may carry a unit address prefix. No prefix = the local/connected unit; * = broadcast to all; a digit such as 01 = a specific daisy-chain address.
    • 
          
  • State values: a COM routes to port 1–4; 0 means open / not routed.
    •

        Switching (SP4T)
        
General form: [Sw_Type]:[Ch]:STATE[:state] — here Sw_Type=SP4T, Ch=A or B. This is exactly what the faceplate above sends when you click a port.

        

          
CommandWhat it doesExample reply

          
            
SP4T:A:STATE?Current port of COM A3

            
SP4T:A:STATE:3Route COM A → port 31

            
SP4T:B:STATE?Current port of COM B0

            
SP4T:B:STATE:4Route COM B → port 41

          
        

      


      
      

        Sequence engine (SEQ)
        
Program a stored list of switch states with dwell times, then run it on the unit.

        

          
CommandWhat it does

          
            
SEQ:STEPS:[n] / SEQ:STEPS?Set / get the number of steps in the sequence

            
SEQ:STEP:[i] / SEQ:STEP?Select / get the active step to edit or read

            
SEQ:STATE:[s] / SEQ:STATE?State(s) for the current step — combined index (8) or per-channel (1:2:2:1)

            
SEQ:DWELLTIME:[t] / SEQ:DWELLTIME?Dwell time for the current step (in the current units)

            
SEQ:DWELLUNITS:[u] / SEQ:DWELLUNITS?Dwell units — U=µs, M=ms, S=s

            
SEQ:CYCLES:[n] / SEQ:CYCLES?Number of times to run the whole sequence

            
SEQ:DIRECTION:[m] / SEQ:DIRECTION?Run direction — 0=forward, 1=reverse, 2=bidirectional

            
SEQ:MODE:[ON|OFF] / SEQ:MODE?Start / stop (and query) the stored sequence

        Other interfaces (per manual)
        
    
          
  • Binary byte-0 protocol: the manual also documents a binary command-code protocol (40=MN, 41=SN, 42=FW, 204/205=SEQ set/get). This USB app uses the ASCII SCPI protocol instead.
    • 
          
  • Network text commands (HTTP / Telnet / SSH on Ethernet units): SETA=[n], SETB=[n], SWPORT?, and the combined info query MCLRFSWITCH?.
